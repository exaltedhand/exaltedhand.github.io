# exhaltedhand.github.io

I don't really expect anyone to find this. This is as much for me to find in the future as for anyone else. This is mostly just here cuz I want somewhere (a site) to share stuff. I guess a public journal without any eyeballs on it. The site is unindexed, and my handle is not used on any other site. This is intentional.

I've wanted to create a neocities page for a long time now. I still do. But the technical hurdles, low as they may be, are daunting. I want to learn the basics of web development, but its an uphill fight. I'm hoping this project will help me in that fight.

Anyways, the plan for this site is to do a write up on a topic about once a month. Topics will vary. Changes will occur. I have a vision for a personal website with sprawling networks of pages that contain links within links, but that might not be in this site's destiny. Regardless, progress in 2026 will start small. This is a living project, almost performance art, were there an audience.
